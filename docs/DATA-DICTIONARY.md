# 拼版与纸耗计算

尺寸单位mm或cm统一到mm，纸张克重gsm为g/m²，纸价为CNY/kg。仅比较整版同方向正交网格的0°与90°，不宣称是任意混排的全局最优。grain=fixed不允许旋转。每个成品四边各加bleed，成品间gap；列数=floor((纸宽+gap)/(成品宽+2bleed+gap))。

净张数=ceil(印量/每张副数)，固定开机损耗单独加，运行损耗=ceil(净张数×loss_pct/100)，不得对含固定损耗的总数重复计百分比。每纸批按due、order_id顺序扣库存；不足整单不放行，库存不为负。余料仅为完整原纸，裁切边料不按原纸返库。毛重=总张数×面积m²×gsm/1000。按每批精确总成本四舍五入到分后最大余额分摊，保证订单成本和纸批总成本相等。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同order_id仅最高version参与生产计算，旧版保留采信证据；同版本业务字段冲突则整组隔离。同纸批库存、克重、纸价与尺寸按Decimal数值比较，数值相同的小数写法视为同一材质。
