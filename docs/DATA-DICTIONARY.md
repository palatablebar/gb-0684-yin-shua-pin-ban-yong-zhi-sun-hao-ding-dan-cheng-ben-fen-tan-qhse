# 拼版与纸耗计算

尺寸单位mm或cm统一到mm，纸张克重gsm为g/m²，纸价为CNY/kg。仅比较整版同方向正交网格的0°与90°，不宣称是任意混排的全局最优。grain=fixed不允许旋转。每个成品四边各加bleed，成品间gap；列数=floor((纸宽+gap)/(成品宽+2bleed+gap))。

净张数=ceil(印量/每张副数)，固定开机损耗单独加，运行损耗=ceil(净张数×loss_pct/100)，不得对含固定损耗的总数重复计百分比。每纸批按due、order_id顺序扣库存；不足整单不放行，库存不为负。余料仅为完整原纸，裁切边料不按原纸返库。毛重=总张数×面积m²×gsm/1000。按每批精确总成本四舍五入到分后最大余额分摊，保证订单成本和纸批总成本相等。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同order_id仅最高version参与生产计算，旧版保留采信证据；同版本业务字段冲突则整组隔离。同纸批库存、克重、纸价与尺寸按Decimal数值比较，数值相同的小数写法视为同一材质。

## 迟到修订工单结算（M8）

已放行（decision=通过 且对账平衡）的纸批为冻结基线，其订单金额与库存快照不得改写。迟到的改印量/改交期工单走独立的"补差结算单（ADJUST）"，绝不重开旧批。

- 路线选择：ADJUST 为默认且唯一可入账路线；REOPEN（在基线期初库存上整批重算）仅生成对比视图，记录类型标 `REOPEN_VIEW_ONLY`，不产生任何入账。
- 可排库存：调整行的期初 = 基线批期末完整原纸余料 + 本批此前累计张数差；减量退库（closing 上升）、增量扣减（closing 下降），库存恒不为负，不足则该单 `REV_SHORTAGE` 隔离、整单不放行。
- 差额来源：逐单 `sheet_delta = 修订gross − 基线gross`；重量差按毛张面积公式同口径计算；批级精确成本差额用带符号最大余数法分摊到订单（`signed_apportion`），保证 订单差额和 = 纸批差额 = 本期总差额。
- 两条路线在同质纸批下批级总差额恒等，但每单原单成本因分摊集合不同（增量分摊 vs 全量重分摊）可相差分币；这正是禁止重开入账的证据。
- 财务勾稽：调整后总额 = 冻结的已放行金额 + 本期差额；`released_amount_immutable=true`。
- 仅 `quantity/due/stock` 为可修订核算字段；材质、尺寸、克重、纸价等契约变更判 `MATERIAL` 隔离，须走新单；基线不存在的订单判 `BASELINE`；仅 note 差异不产生调整行。
- 幂等：结算单ID = 哈希(基线run_id + 修订输入字节 + 参数 + 规则版本)，同修订重跑返回首版、不新增差额。
- 失败恢复：落库前备份当前 latest 到 run_backups，写入或指纹自检失败则整事务回滚并恢复旧版 latest，记录不丢。
- 归档与普通封存同表头同口径，新增 调整/纸批差额/重开对比/修订汇总 记录类型，sha256 覆盖整份CSV。
